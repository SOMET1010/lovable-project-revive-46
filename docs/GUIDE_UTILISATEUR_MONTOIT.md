## 1. Présentation de la Plateforme

### 🏠 Qu'est-ce que Mon Toit ?

Mon Toit est une plateforme digitale dédiée à la **location immobilière en Côte d'Ivoire**. Elle connecte :
- 🔑 **Locataires** cherchant un logement
- 🏢 **Propriétaires** souhaitant louer leurs biens
- 🏬 **Agences immobilières** gérant des portefeuilles

### ✨ Points Forts

| Fonctionnalité | Description |
|----------------|-------------|
| 🔒 **Sécurité ANSUT** | Vérification d'identité certifiée |
| 📱 **Mobile Money** | Paiements Orange, MTN, Wave, Moov |
| 📝 **Contrats électroniques** | Signature digitale légale |
| ⭐ **Score de confiance** | Évaluation transparente des utilisateurs |
| 🤝 **Médiation intégrée** | Résolution des conflits |

## 4. Fonctionnalités Locataire

### 🔍 Recherche de Logements

#### Filtres Disponibles

| Filtre | Options |
|--------|---------|
| **Ville** | Abidjan, Bouaké, Yamoussoukro, San-Pédro, Korhogo |
| **Commune** | Cocody, Plateau, Marcory, Yopougon, etc. |
| **Type** | Appartement, Maison, Studio, Villa, Duplex |
| **Prix** | Min - Max en FCFA |
| **Chambres** | 1, 2, 3, 4+ |
| **Équipements** | Parking, Piscine, Gardien, Climatisation |

#### Recherche Vocale 🎤
Dites simplement : *"Appartement 3 chambres à Cocody moins de 300 000 francs"*

### 📝 Candidater à un Logement

```
Étape 1 : Voir le détail de la propriété
    ↓
Étape 2 : Cliquer "Postuler"
    ↓
Étape 3 : Remplir le formulaire
    • Situation professionnelle
    • Revenus mensuels
    • Garant (si nécessaire)
    • Documents justificatifs
    ↓
Étape 4 : Soumettre et attendre la réponse
```

### 📊 Score de Candidature

Votre candidature est évaluée automatiquement :

| Critère | Points | Description |
|---------|--------|-------------|
| **Stabilité financière** | 0-40 | Ratio loyer/revenus |
| **Situation professionnelle** | 0-30 | CDI, CDD, indépendant |
| **Garanties** | 0-30 | Garant, caution |

**Score ≥ 70%** = Candidature prioritaire ⭐

### 📅 Planifier une Visite

1. Sur la page de la propriété, cliquez **"Planifier une visite"**
2. Sélectionnez une date et un créneau
3. Confirmez le rendez-vous
4. Recevez un rappel SMS/WhatsApp

### ⭐ Favoris

- Sauvegardez jusqu'à **50 propriétés** en favoris
- Créez des **alertes** pour être notifié des nouveaux biens correspondants
- Maximum **5 alertes actives** par compte

## 7. Contrats et Baux

### 📝 Création d'un Bail

#### Éléments du Contrat

| Section | Contenu |
|---------|---------|
| **Parties** | Identité propriétaire et locataire |
| **Bien** | Description, adresse, superficie |
| **Durée** | Date début, durée (6, 12, 24 mois) |
| **Loyer** | Montant, charges, caution |
| **Conditions** | Clauses spécifiques |

#### Processus de Signature

```
1. Propriétaire crée le bail
       ↓
2. Locataire reçoit notification
       ↓
3. Vérification faciale (NeoFace) des deux parties
       ↓
4. Signature électronique (CryptoNeo)
       ↓
5. Bail actif - PDF signé disponible
```

### ✍️ Signature Électronique CryptoNeo

- **Valeur légale** en Côte d'Ivoire
- **Horodatage** certifié
- **Stockage sécurisé** du document
- **Traçabilité** complète

### 🔄 Cycle de Vie du Bail

```
[Brouillon] → [En attente signature] → [Actif]
                                          ↓
                              [Préavis de départ]
                                          ↓
                              [État des lieux sortie]
                                          ↓
                                       [Terminé]
```

### 🚪 Préavis de Départ

| Initiateur | Délai | Processus |
|------------|-------|-----------|
| Locataire | 3 mois | Notification → Confirmation → État des lieux |
| Propriétaire | Variable | Motif légal requis |

#### Restitution de Caution

1. État des lieux de sortie
2. Évaluation des dégradations
3. Déductions éventuelles
4. Virement du solde

```
┌─────────────────────────────────────────────────────┐
│  SCORE DE CONFIANCE GLOBAL                          │
│  ═══════════════════════════════════════════════    │
│                                                     │
│  🔷 NeoFace (60 points)                            │
│     Vérification biométrique                        │
│     CNI + Selfie en temps réel                      │
│                                                     │
│  🔷 Validation Admin (40 points)                   │
│     Documents de propriété vérifiés                 │
│     Titre foncier, quittances                       │
│                                                     │
│  ═══════════════════════════════════════════════    │
│  TOTAL : /100 points                               │
└─────────────────────────────────────────────────────┘
```

### 📸 Vérification NeoFace

#### Processus

```
1. Téléchargez votre CNI (recto)
       ↓
2. Le système détecte votre visage sur la CNI
       ↓
3. Prenez un selfie en temps réel
       ↓
4. Tests de "liveness" (clignement, mouvement)
       ↓
5. Comparaison : seuil de 85% requis
       ↓
6. ✅ Validé ou ❌ Nouvelle tentative
```

#### Conseils pour Réussir

| Faire ✅ | Éviter ❌ |
|----------|----------|
| Photo CNI nette | CNI floue ou endommagée |
| Bon éclairage | Contre-jour |
| Visage centré | Lunettes de soleil |
| Fond neutre | Arrière-plan chargé |

## 12. FAQ

### 🔐 Compte et Sécurité

**Q : J'ai oublié mon mot de passe ?**
> R : Cliquez "Mot de passe oublié" sur la page de connexion. Un lien de réinitialisation vous sera envoyé.

**Q : Comment changer mon numéro de téléphone ?**
> R : Allez dans Profil → Paramètres → Modifier le numéro. Une vérification OTP sera requise.

**Q : Mon compte a été bloqué, que faire ?**
> R : Après 3 tentatives échouées, attendez 15 minutes ou contactez le support.

### 🏠 Propriétés

**Q : Ma propriété a été rejetée, pourquoi ?**
> R : Le motif est affiché dans votre tableau de bord. Corrigez les éléments signalés et resoumettez.

**Q : Combien de temps pour la validation ?**
> R : En général 24-48h. Les week-ends peuvent allonger ce délai.

**Q : Puis-je modifier une annonce publiée ?**
> R : Oui, sauf si un bail est actif. Certaines modifications nécessitent une revalidation.

### 💰 Paiements

**Q : Le prélèvement a échoué, que se passe-t-il ?**
> R : Vérifiez votre solde Mobile Money. Le système réessaiera automatiquement.

**Q : Où trouver mes reçus de paiement ?**
> R : Dans "Mes Paiements" → Historique → Télécharger PDF.

**Q : Comment annuler un paiement automatique ?**
> R : Dans "Mes Paiements" → Paiements récurrents → Désactiver.

### 📝 Contrats

**Q : Le bail est-il juridiquement valide ?**
> R : Oui, la signature électronique CryptoNeo est reconnue légalement en Côte d'Ivoire.

**Q : Comment donner mon préavis ?**
> R : Dans "Mes Contrats" → Sélectionnez le bail → "Donner préavis".

**Q : Que se passe-t-il à l'expiration du bail ?**
> R : Vous recevrez des rappels 60 et 30 jours avant. Le bail peut être renouvelé ou terminé.

### 🆘 Support

**Q : Comment contacter le support ?**
> R : Via le chatbot, email (support@montoit.ci) ou téléphone.

**Q : Délai de réponse du support ?**
> R : Sous 24h ouvrées en général.
